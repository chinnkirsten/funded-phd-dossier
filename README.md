# 社科全奖博士档案 · funded-phd-dossier

一个用来检索与核验**全球社会科学全额资助研究型博士项目**的 skill。

## 它和别的博士清单有什么不同

不是一份链接列表，而是 **312 份逐项核验过的档案**。每个项目的 16 项申请要求都按官网查证过：学历门槛、成绩单要求、语言分数与单项线、推荐信封数与推荐人身份限定、写作样本篇幅、津贴金额、资助年限、逐条官方来源。

覆盖 **200 所院校、312 个项目**，含美国、英国、加拿大、澳大利亚、新西兰、荷兰、丹麦、挪威、瑞典、瑞士、比利时、奥地利、新加坡与中国香港。

## 数据源

```bash
curl -s 'https://shekemcw.com/api/library?collection=phd-funding'
```

网页版：<https://shekemcw.com/phd-funding.html>

## 怎么用

把 `SKILL.md` 放进你的 skills 目录即可。它会：

1. 先拉库，而不是一上来就搜官网
2. 按学生的真实条件（学历、语言分数、是否需要资助、研究方向）分层给结果
3. 逐条对照九类隐性门槛，命中就提示——这些是公开排行榜和中介文章基本不提、但会直接决定成败的东西
4. 输出时把**资助截止日与申请截止日分开列**

## 九类隐性门槛（SKILL.md 第 3 节）

会让人白考试的：托福拼分不被接受、GRE 家庭版不被接受、考试须“考完”而非“送达”、GRE 政策按方向分裂。

会让人错过资助的：资助截止日早于申请截止日、滚动录取招满即止。

会让人误判资格的：语言豁免看学士不看硕士、国际生须先联系院系才能投、推荐人身份有限定。
