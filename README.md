# 社科全奖博士项目爬取器 · funded-phd-dossier

一个 skill，教你自己把**全球社会科学全额资助研究型博士项目**查出来、核准、存成一份能反复用的档案。

## 它不是什么

**不是一份现成清单，也不是查别人数据库的客户端。** 它不带数据，带的是方法。

为什么：全奖项目的截止日、GRE 政策、资助年限每年都在变，任何静态清单出厂就在过期。而学生真正被卡住的地方从来不是"有哪些学校"，是"这一条我到底符不符合、钱到底给几年、哪个日子才是拿钱的那个日子"。这些只能落到官网逐条看。

所以产出是**你自己的库**，随时可复核，出处可追。

## 它给你什么

| 内容 | 作用 |
|---|---|
| **检索入口** | 欧洲带薪博士职位与 studentship 的官方职位库、英国资助主体、德国结构化博士项目、香港统一入口、澳新奖学金页的找法；北美没有集中职位板，给按学科逐校查的办法 |
| **全奖判定四模式** | 什么才算全奖，以及八种"看着像全奖其实不是"的写法 |
| **一条合格记录的 16 项** | 从学历门槛到写作样本篇幅到逐条官方来源，缺一项这条记录就不算成立 |
| **九类隐性门槛** | 公开排行榜和中介文章基本不提，但会直接决定成败 |
| **三类必须主动防的错** | 张冠李戴、链接状态误判、把执行成功当成结果正确 |
| **复核频率表** | 哪类项目多久回查一次 |

## 九类隐性门槛

会让人白考试的：托福拼分不被接受、GRE 家庭版不被接受、考试须"考完"而非"送达"、GRE 政策按方向分裂。

会让人错过资助的：资助截止日早于申请截止日、滚动录取招满即止。

会让人误判资格的：语言豁免看学士不看硕士、国际生须先联系院系才能投、推荐人身份有限定。

这九条是逐条核验三百多个项目的过程中挖出来的，不是从别处抄的。

## 怎么用

把 `SKILL.md` 放进你的 skills 目录。之后描述你的条件（学历、语言分数、研究方向、能否自费），它会带你走检索到核验的全过程，产出结构化记录。

## 一个用这套方法跑出来的样本

社科茅草屋按这套标准跑出了一个库，收录两百所院校、三百多个社会科学博士项目，可以看看产出长什么样、16 项填到什么颗粒度算够：

<https://shekemcw.com/phd-funding.html>

**它是样例，不是你的数据源。** 项目条款每年在变，别人的核验日期不是你的核验日期。
