# 社科全奖博士项目查证手册 · funded-phd-dossier

一个 skill，教你自己把**全球社会科学全额资助研究型博士项目**查出来、核准、存成一份能反复用的档案。

## 它不是什么

**不是一份现成清单，也不是查别人数据库的客户端。** 它不带数据，带的是方法。

为什么：全奖项目的截止日、GRE 政策、资助年限每年都在变，任何静态清单出厂就在过期。而学生真正被卡住的地方从来不是"有哪些学校"，是"这一条我到底符不符合、钱到底给几年、哪个日子才是拿钱的那个日子"。这些只能落到官网逐条看。

所以产出是**你自己的库**，随时可复核，出处可追。

## 它给你什么

| 内容 | 作用 |
|---|---|
| **检索入口** | 欧洲带薪博士职位与 studentship 的官方职位库、英国资助主体、德国结构化博士项目、香港统一入口、澳新奖学金页的找法；北美没有集中职位板，给按学科逐校查的办法 |
| **全奖判定四模式** | 什么才算全奖，以及八种"看着像全奖其实不是"的写法 |
| **两层记录法** | 先建资助口径层（判定真全奖 + 三个官方链接），真要申的四到八个项目再补齐 16 项申请档案，建库不被全项要求压垮 |
| **十类隐性门槛** | 公开排行榜和中介文章基本不提，但会直接决定成败 |
| **三类必须主动防的错** | 张冠李戴、链接状态误判、把执行成功当成结果正确 |
| **复核频率表** | 哪类项目多久回查一次 |
| **一条填好的样本记录** | 拿芝大哈里斯真实项目演示 16 项填到什么颗粒度算够 |

## 十类隐性门槛

会让人整个申请作废的：奖学金国籍名单不含中国大陆（ADB-JSP、JJ-WBGSP、Commonwealth、Australia Awards 等渠道已逐条核实）。

会让人白考试的：托福拼分不被接受、GRE 家庭版不被接受、考试须"考完"而非"送达"、GRE 政策按方向分裂。

会让人错过资助的：资助截止日早于申请截止日、滚动录取招满即止。

会让人误判资格的：语言豁免看学士不看硕士、国际生须先联系院系才能投、推荐人身份有限定。

这十条是逐条核验上千个项目的过程中挖出来的，不是从别处抄的。

## 怎么用（三种都行，从易到难）

**一、复制进任意 AI 对话（最简单，推荐大多数人）**
打开 [SKILL.md](SKILL.md)，全选复制，粘贴进你在用的 AI（Claude、ChatGPT、Kimi、豆包都行），然后一句话说明你的条件：学历、专业、语言分数、想去的地区、能否接受部分自费。AI 会按手册的规矩带你走完检索到核验的全过程——先问清你的七项条件，再查项目，每条都给官方链接。

**二、不用 AI，自己当手册照着做**
手册本身就是一份核对清单：第 0 节先自查条件，第 1 节告诉你去哪些官方入口找，第 3 节教你判断一个项目是不是真全奖，第 6 节是十个最容易踩的坑。打印出来对着勾也行。

**三、Claude Code / 支持 skills 的工具**
在 skills 目录下新建文件夹 `funded-phd-dossier/`，把 `SKILL.md` 放进去（必须以文件夹为单位）。之后直接描述需求即可自动触发。

无论哪种用法，一条铁律不变：**AI 给的任何项目信息，申请前都要自己打开官方链接再看一遍。** 手册教的正是怎么核，而不是替你信。

## 一个用这套方法跑出来的样本

社科茅草屋按这套标准跑出了一个持续扩充的库（数百所院校、数百个项目），可以看看产出长什么样、各项填到什么颗粒度算够：

<https://shekemcw.com/phd-funding.html>

**它是样例，不是你的数据源。** 项目条款每年在变，别人的核验日期不是你的核验日期。
